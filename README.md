## Mod Description

This mod adds neat little particle effects to leaf blocks.

![](https://i.imgur.com/Tek7xJe.gif)

## Features

### Falling Leaves

Similar to the falling leaves introduced in Minecraft 1.21.5, leave blocks let leaf particles fall. But unlike the vanilla behavior, the leaves are fully customizable and compatible with different leaf types and mods.

Each setting can be disabled.

See [here](docs/leaf_overview.md) for a guide of leaf drop changes

#### Wind

Falling Leaves uses a simple wind system depending on the weather. From no wind to hurricane the wind affects the fall of the leaves.

### Falling Snow

Additionally to the leaves, leaves will drop snow particles when they are covered in snow.

## Compatibility

Falling Leaves is fully compatible with mods adding their own trees with leaf blocks and resource packs. Only to change the texture of the leaf type, they must be configured.

Mods with explicit compatibility (customized leaves):

- [Biomes O' Plenty](https://www.curseforge.com/minecraft/mc-mods/biomes-o-plenty)
- [Oh The Biomes You'll Go](https://www.curseforge.com/minecraft/mc-mods/oh-the-biomes-youll-go)

And Falling Leaves uses the season system of **[Serene Seasons](https://www.curseforge.com/minecraft/mc-mods/serene-seasons)** to change the leave spawns depending on the season.
